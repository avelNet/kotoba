# Котоба — японский в Telegram

Mini App с интервальными повторениями (как Anki) + бот, который каждое утро присылает кнопку «Начать занятие».

- **Колоды:** хирагана (104 знака) → катакана (104) → слова N5 (~320) → кандзи N5 (~100). Открываются по очереди.
- **Новые карточки** сначала показываются с ответом, потом проверяются в том же занятии.
- **Повторения** по упрощённому SM-2: «Снова / Трудно / Хорошо / Легко», интервал растёт, забытое возвращается.
- **Прогресс** хранится в облаке Telegram (CloudStorage) и дублируется в браузере. Сервер не нужен.
- Озвучка японским голосом iOS, тактильный отклик, тема Telegram, резервная копия текстом.

## Установка (≈10 минут)

1. **Репозиторий.** Создай публичный репозиторий (например, `avelNet/kotoba`) и залей туда эти файлы.
2. **GitHub Pages.** Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
   Через минуту приложение будет на `https://avelnet.github.io/kotoba/`.
3. **Бот.** В @BotFather — `/newbot` (или возьми существующего бота), скопируй токен.
4. **Свой chat_id.** Напиши боту что угодно, потом открой
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id": ...}`.
5. **Секреты.** Settings → Secrets and variables → Actions:
   - *Secrets:* `BOT_TOKEN`, `CHAT_ID`
   - *Variables:* `APP_URL` = адрес из шага 2
6. **Кнопка меню.** Actions → Daily reminder → Run workflow → mode = `setup`.
   Слева от поля ввода в чате с ботом появится кнопка «Учить».
7. **Проверка.** Run workflow с mode = `remind` — должно прийти сообщение с кнопкой.

Дальше напоминание будет приходить само каждый день около 7:47 (Новосибирск).
Время меняется в `.github/workflows/reminder.yml` (cron в UTC, Новосибирск = UTC+7).

## Как добавлять материал

Всё лежит в `data.js`, по строке на карточку:

- слова: `кана|кандзи|перевод`, например `がっこう|学校|школа`
- кандзи: `кандзи|он|кун|значение`

Новые строки дописывай **в конец** блока, тогда прогресс не собьётся.
Удалять или переименовывать уже выученные слова не стоит: id карточки = кана + кандзи.

## Полезно знать

- Новый день начинается в 4:00, как в Anki.
- Лимит новых карточек в день меняется в настройках приложения отдельно для каждой колоды.
- GitHub отключает расписание в публичном репозитории, если в нём 60 дней не было коммитов.
  Если напоминания перестали приходить, сделай любой коммит или включи workflow заново во вкладке Actions.
- Приложение работает и просто в браузере (Safari), но тогда прогресс хранится только на этом устройстве.
