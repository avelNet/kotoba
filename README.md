# Котоба — японский в Telegram

Mini App с интервальными повторениями (как Anki) + бот, который каждое утро присылает кнопку «Начать занятие».

- **Колоды:** хирагана (104 знака) → катакана (104) → слова N5 (~350) → кандзи N5–N4 (~280) → слова в кандзи, плюс свои слова.
- **Новые карточки** сначала показываются с ответом, потом проверяются в том же занятии.
- **Повторения** по упрощённому SM-2: «Снова / Трудно / Хорошо / Легко», интервал растёт, забытое возвращается.
- **Прогресс** хранится в облаке Telegram (CloudStorage) и дублируется в браузере. Сервер не нужен.
- Озвучка японским голосом iOS, тактильный отклик, тема Telegram, резервная копия текстом.

## Установка (≈10 минут)

1. **Репозиторий.** Создай публичный репозиторий (например, `avelNet/kotoba`) и залей туда эти файлы.
2. **GitHub Pages.** Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
   Через минуту приложение будет на `https://avelnet.github.io/kotoba/`.
3. **Бот.** В @BotFather — `/newbot` (или возьми существующего бота), скопируй токен.
4. **Свой chat_id.** Напиши боту что угодно, потом открой
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id": ...}`.
5. **Секреты.** Settings → Secrets and variables → Actions:
   - *Secrets:* `BOT_TOKEN`, `CHAT_ID`
   - *Variables:* `APP_URL` = адрес из шага 2
6. **Кнопка меню.** Actions → Daily reminder → Run workflow → mode = `setup`.
   Слева от поля ввода в чате с ботом появится кнопка «Учить».
7. **Проверка.** Run workflow с mode = `remind` — должно прийти сообщение с кнопкой.

Пока сервер (ниже) не подключён, напоминание приходит одно, тебе, около 7:47 по Новосибирску.

## Публичная версия: сервер на Cloudflare (бесплатно)

Сервер нужен для трёх вещей: напоминания **всем** пользователям в их часовом поясе,
**статистика удержания** (команда `/stats` в боте) и **отзывы** (из приложения и просто сообщением боту).
Код — `worker/worker.js`. Прогресс пользователей по-прежнему хранится в облаке Telegram, а не на сервере.

1. **Аккаунт.** Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатный план, карта не нужна).
2. **База.** Storage & Databases → D1 → *Create* → имя `kotoba`. Таблицы сервер создаст сам.
3. **Воркер.** Workers & Pages → *Create* → *Worker* → имя `kotoba-api` → *Deploy*.
   Потом *Edit code*, заменить всё содержимым `worker/worker.js` → *Deploy*.
   Адрес будет вида `https://kotoba-api.<имя>.workers.dev`.
4. **Привязка базы.** Воркер → Settings → Bindings → *Add* → D1 database → Variable name `DB`, база `kotoba`.
5. **Переменные воркера.** Settings → Variables and Secrets:
   - `BOT_TOKEN` (Secret) — токен бота
   - `WEBHOOK_SECRET` (Secret) — любые 30+ латинских букв и цифр
   - `ADMIN_SECRET` (Secret) — другие 30+ букв и цифр
   - `SALT` (Secret) — ещё одна случайная строка
   - `ADMIN_CHAT_ID` (Text) — твой chat_id
   - `APP_URL` (Text) — `https://avelnet.github.io/kotoba/`
6. **GitHub.** Settings → Secrets and variables → Actions:
   - *Secrets:* добавь `ADMIN_SECRET` и `WEBHOOK_SECRET` (те же строки, что в воркере)
   - *Variables:* `API_URL` = адрес воркера из шага 3
7. **Приложение.** В `config.js` впиши `api: 'адрес воркера'` (и `donate`, когда будет ссылка на донат).
8. **Включить.** Actions → Daily reminder → Run workflow → mode = `setup`. Бот переключится на сервер.
9. **Проверка.** Напиши боту `/start` — придёт приветствие. Потом `/stats` — придёт статистика.

После шага 8 напоминания идут через сервер: каждый час Actions спрашивает, у кого сейчас «его» час
(по умолчанию 8:00, меняется в настройках приложения), и шлёт тем, кто сегодня ещё не занимался.
Кто не нажал у бота «Старт», напоминаний не получает — это касается и тебя.

**Что видно в статистике:** сколько человек открывали приложение, сколько вернулись на 2-й день,
занимаются через 7+ и 14+ дней, активные и новые по дням. Для статистики хранится только хэш id,
для напоминаний — chat_id, часовой пояс и выбранный час.

**Отзывы.** Любое сообщение боту (не команда) и форма «Написать разработчику» в профиле приходят тебе.
Ответь на такое сообщение реплаем — бот перешлёт ответ автору.

**Лимиты.** Бесплатные Workers и D1 рассчитаны на десятки тысяч запросов и записей в день; приложение пингует
сервер не чаще раза в 5 минут. Если упрёшься — `worker.js` почти без изменений запускается на Node на своём
сервере (база D1 — это SQLite), а бот переключается заново через `setup` с новым `API_URL`.

## Как добавлять материал

Всё лежит в `data.js`, по строке на карточку:

- слова: `кана|кандзи|перевод`, например `がっこう|学校|школа`
- кандзи: `кандзи|он|кун|значение`

Новые строки дописывай **в конец** блока, тогда прогресс не собьётся.
Удалять или переименовывать уже выученные слова не стоит: id карточки = кана + кандзи.

## Полезно знать

- Новый день начинается в 4:00, как в Anki.
- Лимит новых карточек в день меняется в настройках приложения отдельно для каждой колоды.
- GitHub отключает расписание в публичном репозитории, если в нём 60 дней не было коммитов.
  Если напоминания перестали приходить, сделай любой коммит или включи workflow заново во вкладке Actions.
- Приложение работает и просто в браузере (Safari), но тогда прогресс хранится только на этом устройстве.
